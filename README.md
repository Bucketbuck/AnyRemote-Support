# AnyRemote 支持

AnyRemote 是一款免费的 iPhone / iPad 蓝牙灯光遥控应用。无需注册账户，没有广告、内购或订阅。

## 开始使用

1. 给灯具通电，并开启 iPhone / iPad 蓝牙。
2. 在 AnyRemote 首页选择「添加灯」，允许蓝牙访问，选择设备。
3. 保存后，点击灯具名称展开控制。可用项目取决于灯具支持的接口。
4. 可以给设备重命名、分文件夹，并保存自定义氛围。

## 兼容性

需要 iOS / iPadOS 17 或更新版本，以及受支持的蓝牙灯具。本应用不是通用红外遥控器，也不保证兼容所有蓝牙设备。

双区灯的上灯提供受支持的白光、颜色与亮度控制，下灯目前仅提供独立开关。下灯调光尚未验证，不提供该控制。部分白光灯的实验性适配需要实际设备确认。

## 定时、小组件与律动

- 定时动作在应用处于活动状态时执行；后台通知是提醒，不代表灯具会在后台自动执行。
- 小组件需要先打开应用并保存灯具；实际连接受蓝牙范围及系统运行状态影响。
- 律动在点击「开始」后请求麦克风权限，仅在本机分析声音音量，不录音、不上传，也不捕获其他应用的内部音频。离开氛围页或应用进入后台时停止。

## 常见问题

找不到设备：确认灯具通电、处于蓝牙范围内，检查系统设置中的蓝牙授权，尝试停止搜索后重新搜索。避免同时用其他应用连接灯具。

操作没有效果：确认选中了正确的灯和控制区域。显示写入成功仅表示蓝牙传输结果，不保证物理灯具已改变。不兼容的设备可能需要适配。
